# Disease Prediction System 🏥

A Machine Learning based web application that predicts possible diseases based on user symptoms and provides quick health suggestions.

## Project Overview
This project helps users enter symptoms and receive predicted disease results using a trained machine learning model.

The system was developed to demonstrate data preprocessing, model training, prediction, and basic web integration.

## Features
- User-friendly interface
- Symptom-based disease prediction
- Machine Learning model integration
- Fast prediction results
- Simple and responsive design

## Accuracy
Achieved approximately **80% prediction accuracy** during testing.
